ImageSVM - Handwritten Digit Recognition
Project Overview
This project uses Support Vector Machine (SVM) to classify handwritten digits from the Scikit-learn Digits dataset.

**Technologies Used**
Python
NumPy
Matplotlib
Scikit-learn
FastAPI
Pickle

**Machine Learning Algorithm**
Support Vector Machine (SVM)

**Features**
Image Classification
Digit Recognition
Model Persistence using Pickle
FastAPI Integration


**Dataset**
Scikit-learn Digits Dataset
  1797 images
  8x8 grayscale images
  Labels 0-9
  
**Run the API**
python -m uvicorn app:app --reload
